03 · Trabajar en el sistema

npm run dev     este servidor
npm run build   regenera dist/ desde tokens/ y assets/
npm run check   audita manual ↔ tokens
  • La fuente de verdad es tokens/tokens.json: nunca edites dist/.
  • Si cambias algo y no lo ves, recarga con Cmd+Shift+R (Chrome cachea los scripts).
  • Decisiones de marca en docs/decisions/.
